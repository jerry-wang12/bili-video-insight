# 分析深度与阅读产物

普通视频分析默认使用这份说明，生成详细解读与连续分段释义，无需用户逐次要求；用户明确缩小范围时遵从用户要求。脑图是导航，不能替代解释。

撰写内容使用内置 [忠实概括与中文编辑 Skill](../skills/video-faithful-summary/SKILL.md)。完整材料中的判断、依据与限定先还原，再编辑语言；不能把证据校验当作语义审核。

## 内容质量

从材料中识别论点、论据、推理步骤、例子、限定和前后衔接，选择对理解有帮助的内容写入节点正文；不要求每个节点机械套齐栏目。明显有多个推理环节时，保留过程，不只写最终结论。概念密集的材料要说明容易混淆的区别。语音口误、作者简化与整理者补充分别标明。

按内容决定层级和长度，避免把材料压缩成固定条目数，也不要为了显得详细而添加材料没有支持的解释。完整阅读范围和解释深度是不同的质量维度，均应核对。

## 数据格式

保留已有 title、children、body、evidence；body 可用空行分隔多个段落。增补字段：

```json
{
  "title": "材料主题",
  "notice": "真实覆盖范围；内容属于分析还是原文。",
  "summary": "帮助理解全片的问题线索。",
  "children": [
    {"title": "主题", "body": "结论与推理。\n\n例子和限定。",
     "evidence": ["实际转写ID"]}
  ],
  "timeline": [
    {"start": 0, "end": 75, "title": "这段讨论的问题",
     "body": "用自己的话概括这段的推进，不复制原文。",
     "evidence": ["范围内的实际转写ID"]}
  ],
  "review": "识别勘误、概念限定和补充来源，按空行分段。"
}
```

timeline 按语义转折划分，不必机械按等长时间切割。每段要有真实引用和非空正文；时间有限、递增、不重叠、不超出素材时长，引用的证据必须与该范围相交。声明完整覆盖时，另核对没有漏段，特别是开头、广告和结尾；验证器不会自动证明内容涵盖完整。

render / finish 会生成 reading.html，保留详细正文并提供检索；有 timeline 时生成 segments.md，有 review 时生成 review.md。FreeMind 正文进入节点备注；脑图仍保留完整树。重渲染取消可选字段时移除旧的对应文件，finish 后已有 ZIP 失效，需重新 bundle。

## 阅读页呈现

阅读页的 HTML、CSS 和交互模板位于 assets/reader.*，导出时全部内嵌到独立 HTML，无外部字体、脚本或图片请求。默认使用安静的莫兰迪色系，单一灰蓝强调色；重点靠字号、字重、留白与浅底区分。正文不展示内部证据编号或证据数量，真实引用仍保留在文字与脑图导出中。覆盖说明及复核保留在页末折叠区，不与正文抢占位置。

可选呈现字段不改变分析正文与导出树，旧格式仍可使用：

- 根节点 display_title（简短页面标题）、lede（一句导语）。视频来源沿用 summary 中第一个 HTTPS Markdown 链接，务必核对链接文字与作者。
- 章节 nav_title（短导航）、display_title（阅读标题）、time_label（时间范围）、focus（本章重点）、sequence（分析线索字符串数组）。线索不必表示严格因果或历史先后，内容不得误导。
- 主题 takeaway（一句关键结论）、emphasis（正文中要强调的词语数组）。从论证中提取，不添加未经支持的说法；强调不改变原有文字。
- 主题 secondary=true 将背景或限定放入本章末尾的折叠区，全文保留且可搜索；不能借此隐藏关键论据或反例。搜索会展开匹配的折叠正文，清除后恢复搜索前的折叠状态。
- 根节点、章节与主题均可提供 map_label，作为脑图中的短标签；缺省使用 nav_title 或 title。标签只压缩表达，不能改变正文的结论。mindmap.html 使用中心节点与左右分支，点击节点读取原有正文；mindmap.svg 保留全部节点，HTML 支持平移、缩放、只看主线及 PNG 导出。模板在 assets/mindmap.*，布局在 scripts/mindmap.py，无外部依赖。PNG 导出失败可下载 SVG。

不要求给每个材料填齐字段，也不要把所有句子都标成重点。

## 原始分段与释义的区别

work/transcript.json/.txt/.srt 已保存机器识别的时间段，不等于作者书面原稿或人工校勘稿。时间释义来自内容分析，不能把它命名为原文。完整逐字交付按用户材料权限和适用内容规则判断；仅给外部链接时不把完整受保护内容转存为交付文件。通用导出默认不复制原始转写，交付包也不包含它。
