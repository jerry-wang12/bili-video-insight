# 忠实概括与中文编辑

在撰写视频分析前读取本文件。输入是已取得的转写、时间点和画面证据；本 Skill 负责内容，不重新获取媒体。不把自动校验通过等同于概括正确。

## 先还原论证

完整阅读材料，按实际转折划分主题。先在任务的 `work/` 留一份简短论证笔记：本段在回答什么问题、作出什么判断、凭什么、如何接到下一段，并记下支持它的时间或证据 ID。正文无需套用这些栏目。

分清讲述者的观点、引用对象的观点、被批评的观点及广告。保留原来的判断强度和范围：必然、趋势、可能、条件成立下的结论不能互换。不要把作者的明确结论改成开放问题，也不要把例子提升为证明。

摘要忠实表达视频的立场；事实核查另写复核记录。不能为了显得审慎，在每段加入“在作者框架中”“可能”“并非必然”等材料没有的弱化语。开篇说明观点来源即可；遇到真实的归属歧义或限定时，再明确是谁在说、条件是什么。

## 再写成自然中文

用具体关系和动作串起论证。标题尽量让人一眼知道问题或结论，正文保留理解结论所需的中间环节、关键例子和反作用因素。精简重复，不能删掉推理来换取短句。

一句重点必须概括这一节的核心判断，不能只是“需要区分三个问题”等编辑提示。脑图节点提取同一论证的短标签，不另写一套泛泛而谈的观点；详细解释放在节点备注或阅读页。

避免名词堆叠、翻译腔和机械套语。比如虚构材料明确说“疏通河道能排走积水，却无法解决持续暴雨”时，概括为“疏通河道缓解积水，持续暴雨仍会造成内涝”，不要改成“在作者框架中，排水关系可能存在适用边界”。修辞服务于意思，不添材料没有的类比和评价。

## 逐项回看材料

写完后先核对每个标题、重点句和脑图标签，再核对正文与分段释义：判断是否来自相应材料？条件、因果方向和反方观点是否还在？有无漏掉决定结论的后半句？证据编号存在只说明可以回溯，仍须读对应上下文。

最后单独做一次语言编辑：读者不用看视频，也能顺着文字理解作者如何走到结论。识别错字不改原始转写，术语勘误与整理者补充写进复核记录；正文中确需补充时明确标注。

交付前把覆盖范围、关键修订及未解决的歧义记录在任务 `work/`。不要声称本 Skill 能保证语义忠实，也不要用字数、节点数或证据数量代替内容审阅。
